# ROVER 高速公路模拟控制台

手机优先的可交互网页，支持在线访问和本地运行，未连接真实车辆。无外部依赖、无需构建。AI 助手采用本地指令解析，不调用外部 AI 服务。

## 阿里云部署

访问地址：<http://39.97.244.43/rover/>。网页由已有阿里云服务器的 Caddy 静态服务托管，不需要 ChatGPT 登录。

当前本地版本只需要 `dist` 中的 8 个文件，无需安装 Node.js、数据库或构建工具。资源使用相对路径，同时支持站点根目录和 `/rover/` 子目录；子目录网址需以 `/` 结尾。部署记录见 `deploy/ALIYUN.md`。

`deploy/ALIYUN.md`、`deploy/SHA256SUMS` 与 `deploy/aliyun-static-install.sh` 保留首次发布的 6 文件版本和固定提交校验信息，不能作为当前版本的安装清单。以后更新线上版本时，需另行打包并校验全部 8 个文件，包括新增的 `traffic.js` 与 `lane-control.js`；当前本地功能尚未更新线上部署。

## 本地运行

```sh
git clone https://github.com/loyee001/xinduyuhang.git
cd xinduyuhang
node serve.mjs
```

电脑打开 `http://localhost:4317`。手机与电脑连接同一个 Wi-Fi 后，打开终端打印的 `Same Wi-Fi preview` 地址；电脑需保持服务运行。可用 `PORT=4318 node serve.mjs` 更改端口。

## 驾驶与制动

- 三条普通车道与右侧应急车道，第一人称实时画面、护栏、指示牌和连续延伸的道路。应急车道有独立路面、黄色外缘及 SOS 标识，进入后显示红色警报。优先使用 WebGL，支持 Canvas 2D 备用渲染。目标渲染帧率 30 FPS，界面显示实测帧率。
- 前进目标速度仍可设为 **100 m/s（360 km/h）**，实际驾驶始终遵守所在路段的 **120 / 100 / 80 km/h** 限速（约 33.3 / 27.8 / 22.2 m/s）。油门加速到设定速度与道路限速中的较低值；进入更低限速路段时，超速会触发自动制动，速度按物理模型逐渐降至限速后释放刹车，不会直接跳变或锁定为急停。手动与 AI 驾驶均遵守该规则。
- 按住油门加速；松开油门后因惯性继续行驶，由空气阻力和滚动阻力逐渐减速。降低个人目标速度只限制动力；道路超速保护仍独立工作。
- 周围有独立行驶的轿车和卡车，含同向三车道与对向车流；其他车辆会跟车减速。车流量可切换 **较少 / 中等 / 拥挤**，场景内分别模拟 **42 / 78 / 174 辆车**；拥挤模式有更短车距和更低巡航速度。切换时围绕当前位置重建车流，并在自车前后留出生成间隙，不改变车辆位置或驾驶状态。路段限速每公里循环，路牌与状态栏同步。
- **D 前进 / R 倒车**控制行驶方向。行驶中请求换挡会先制动至完全停稳，再换向；不能瞬间反转。R 挡最高 **5 m/s（18 km/h）**，仍按住同一个油门踏板倒车，画面自动朝后，路况栏显示同车道后车距离。倒车也有惯性、制动距离与车辆碰撞。
- 左右按钮每次点按只选择相邻一条车道；松手后自动完成变道、回正并保持车道中央，不会持续转向。变道途中再次点按会提示先等待到达，不连续排队跨越多条车道。停车时只预选目标，按油门起步后才移动。键盘 A / D / 左 / 右执行相同操作，长按不会重复变道；前进和倒车的左右均按道路方向选择。
- 从右侧普通车道继续向右，会驶入应急车道。车辆中心实际越过普通车道右边界（`x > 5.625 m`）后，立即提示并施加全力紧急制动、锁定油门；速度按物理过程下降，仍有制动时间和距离。停稳后点击 **“解除并返回右车道”** 只选择返回目标，不自动加速；需要重新按住油门驶回，回到右车道中央后解除警报。
- 键盘 W / 上为油门，S / 下为常规刹车，R 切换前进 / 倒车，空格为持续常规制动。
- 刹车踏板施加 55% 制动力；“常规制动至停止”持续制动。紧急制动施加全力刹车并锁定控制，停稳后才可解除。
- 画面显示制动走廊和预计停车线，数据区显示当前速度、加速度、里程、预计急刹距离和实测制动距离。完整停车结果会保留，未停车就松开刹车的测量取消。
- 干燥 / 湿滑路面改变轮胎附着力。为了保持单次测量条件一致，制动过程中不能切换路面。
- 失焦、进入后台、画面失效或断开模拟连接会触发全力制动。重新打开页面时补算停车过程；不会通过直接清零速度实现刹车。

## 物理模型

平直道路上的简化车辆动力学，每步不超过 1/120 秒：

- 质量 1,400 kg，轴距 2.7 m，底层模型的前进上限为 100 m/s，倒车上限为 5 m/s；网页驾驶时另受实际路段限速约束。
- 驱动力受 8,000 N 最大牵引力、650 kW 峰值功率及路面附着力限制。
- 空气阻力 `F = 0.5 × ρ × CdA × v²`，空气密度 1.225 kg/m³，CdA 0.66 m²。
- 滚动阻力 `F = Crr × m × g`，Crr = 0.012，g = 9.81 m/s²。
- 干燥摩擦系数 μ = 0.85，湿滑 μ = 0.45。转向采用自行车模型，转向角变化有速率限制，横向与纵向轮胎力受附着圆约束。
- 制动距离通过与车辆运动相同的阻力和制动模型计算。预计急刹距离是**当前速度下全力直线制动的距离，不包含反应距离**；实测值从踩下刹车起累计真实模拟路径，前进、倒车均计为正距离。常规制动、自动限速制动、转弯或碰撞会让实测值与全力直线预测不同。
- 三条普通车道中心位于 `x = -3.75 / 0 / 3.75 m`；右应急车道范围为 `5.625～8.625 m`、中心为 `7.125 m`。车辆中心的护栏限制为左侧 `-6.45 m`、右侧 `7.95 m`，应急车道能够容纳整车。
- 变道控制器通过转向输入跟踪目标车道，接近中央时回正；它不直接修改车辆位置或朝向，仍使用自行车模型与轮胎附着力限制。
- 护栏采用简化的沿墙擦行模型：接触时最多损失 6% 速度（随碰撞角度变化），持续摩擦额外增加 0.4 m/s² 阻力。**护栏接触本身**不会触发紧急制动、锁定油门或取消驾驶；向内转向可以脱离。右侧应急车道的进入保护优先，因此通常会在到达右护栏之前开始全力制动。
- 周围车辆使用跟车模型及扫掠碰撞检测，避免高速穿车；倒车时根据实际运动方向处理后车接触。碰撞处理只改变运动，不直接操作玩家的制动开关；若接触后车辆进入应急车道，仍会触发应急车道保护。车辆模型不包含真实车体变形。
- 电池按 60 kWh 容量、初始 86% 电量、驱动效率和附件功率累计耗能；设备面板显示电量与即时功率。

模型不包含道路坡度、悬挂、轮胎温度、制动热衰减、真实车辆标定、交通车辆变道或碰撞车体变形。它是交互式物理演示，模拟数值不代表某款真实车辆的制动性能。

## AI 指令演示

支持 `加速到 30 米每秒然后刹车`、`加速到 100 米每秒然后刹车`、`制动测试`、`前进 200 米`、`倒车 10 米`、`刹车停止`、`紧急制动`。

制动测试先加速到道路允许的目标速度，再全力制动并记录距离。例如在 120 km/h 路段输入“加速到 100 米每秒然后刹车”，计划会调整为约 33.3 m/s，再执行制动，不会尝试突破路段限速。跨入其他限速路段时，实际目标随道路限速调整。

前进与倒车任务在行驶指定距离后才开始制动，因此总行驶距离还会包含制动过程；计划中会明确显示这一点。反向任务先停稳换挡。任务先展示计划，点击“开始执行”后运行，手动操作会接管任务。急停解除不会自动恢复旧任务。有车流时，即使已按限速调整，目标速度仍可能无法达到；制动测试 60 秒仍未达速会结束加速、保留自然滑行并提示接管，不报告虚假的制动成绩。

## 文件与检查

- `dist/index.html` / `dist/style.css`：响应式界面。
- `dist/app.js`：驾驶交互、实时显示、任务解析与执行。
- `dist/physics.js`：可单独运行的车辆物理模型。
- `dist/lane-control.js`：车道目标、自动变道和居中转向控制。
- `dist/traffic.js`：车流、跟车、车辆接触和路段限速。
- `dist/simulator.js`：高速公路、车辆、限速牌、相机与制动距离可视化。
- `tests/*.test.cjs`：动力学、交通、制动距离及驾驶界面集成检查。
- `dist/health.json`：同源站点往返延迟测量端点。
- `serve.mjs`：本地静态服务。

```sh
node --test tests/*.test.cjs
node --check dist/app.js
node --check dist/lane-control.js
node --check dist/simulator.js
```

页面提供可选 WebMCP 接口：读取当前模拟状态、请求相邻车道变道、准备任务、触发全力制动。所有接口与界面共用同一车辆状态，均不控制真实硬件。

检查范围包含三档车流与安全切换、前进和倒车的动力学与制动距离、停稳换挡、倒车接触与后车跟随、跨路段自动限速、离散变道与居中、应急车道制动与手动恢复，以及底层护栏擦行和 AI 任务有界结束。网页测试以道路允许速度为准，100 m/s 仅保留为底层模型上限和可输入的目标值。线上部署记录仍以 `deploy/ALIYUN.md` 为准。

上一版三档车流与倒车功能的本地验证记录：浏览器在 390 / 320 px 宽度下无横向溢出，拥挤车流实测约 30 FPS，无控制台警告或错误。倒车 10 米任务实际倒行 11.457 m（含 1.457 m 制动距离）；输入 100 m/s 的制动测试按当前 120 km/h 路段限速执行，实测制动距离 64.445 m。这些记录不替代本次变道功能的验证，以上本地功能尚未更新线上部署。

自动变道与应急车道版本验证：82 项自动检查全部通过，覆盖干湿路面、前进/倒车、长按去重、松手居中、应急车道制动、停稳解除及再次进入。浏览器实测正常右变道收敛至 x=3.750 m 并回正；再次向右实际进入应急车道后停车，保留约 21.4 m 制动距离及警报，解除后保持静止等待新驾驶操作。390 / 320 px 手机布局无横向溢出，实测约 30 FPS。
