# ROVER 高速公路模拟控制台

手机优先的可交互网页，支持在线访问和本地运行，未连接真实车辆。无外部依赖、无需构建。AI 助手采用本地指令解析，不调用外部 AI 服务。

## 阿里云部署

访问地址：<http://39.97.244.43/rover/>。网页由已有阿里云服务器的 Caddy 静态服务托管，不需要 ChatGPT 登录。

当前本地版本只需要 `dist` 中的 7 个文件，无需安装 Node.js、数据库或构建工具。资源使用相对路径，同时支持站点根目录和 `/rover/` 子目录；子目录网址需以 `/` 结尾。部署记录见 `deploy/ALIYUN.md`。

## 本地运行

```sh
git clone https://github.com/loyee001/xinduyuhang.git
cd xinduyuhang
node serve.mjs
```

电脑打开 `http://localhost:4317`。手机与电脑连接同一个 Wi-Fi 后，打开终端打印的 `Same Wi-Fi preview` 地址；电脑需保持服务运行。可用 `PORT=4318 node serve.mjs` 更改端口。

## 驾驶与制动

- 三车道高速公路，第一人称实时画面、护栏、路肩、指示牌和连续延伸的道路。优先使用 WebGL，支持 Canvas 2D 备用渲染。目标渲染帧率 30 FPS，界面显示实测帧率。
- 目标速度可调至 **100 m/s（360 km/h）**。按住油门加速；松开油门后因惯性继续行驶，由空气阻力和滚动阻力逐渐减速。降低目标速度只限制动力，不会直接修改车速。
- 周围有独立行驶的轿车和卡车，含同向三车道与对向车流；其他车辆会跟车减速。路段限速按 120 / 100 / 80 km/h 每公里循环，路牌与状态栏同步。超速仅提示，不替你踩刹车。
- 左右按钮控制转向，可与油门或刹车同时按住。键盘 W / 上为油门，S / 下为常规刹车，A / D / 左 / 右为转向，空格为持续常规制动。
- 刹车踏板施加 55% 制动力；“常规制动至停止”持续制动。紧急制动施加全力刹车并锁定控制，停稳后才可解除。
- 画面显示制动走廊和预计停车线，数据区显示当前速度、加速度、里程、预计急刹距离和实测制动距离。完整停车结果会保留，未停车就松开刹车的测量取消。
- 干燥 / 湿滑路面改变轮胎附着力。为了保持单次测量条件一致，制动过程中不能切换路面。
- 失焦、进入后台、画面失效或断开模拟连接会触发全力制动。重新打开页面时补算停车过程；不会通过直接清零速度实现刹车。

## 物理模型

平直道路上的简化车辆动力学，每步不超过 1/120 秒：

- 质量 1,400 kg，轴距 2.7 m，最高车速 100 m/s。
- 驱动力受 8,000 N 最大牵引力、650 kW 峰值功率及路面附着力限制。
- 空气阻力 `F = 0.5 × ρ × CdA × v²`，空气密度 1.225 kg/m³，CdA 0.66 m²。
- 滚动阻力 `F = Crr × m × g`，Crr = 0.012，g = 9.81 m/s²。
- 干燥摩擦系数 μ = 0.85，湿滑 μ = 0.45。转向采用自行车模型，转向角变化有速率限制，横向与纵向轮胎力受附着圆约束。
- 制动距离通过与车辆运动相同的阻力和制动模型计算。预计急刹距离是**当前速度下全力直线制动的距离，不包含反应距离**；实测值从踩下刹车起累计真实模拟路径。常规制动、转弯或碰撞会让实测值与全力直线预测不同。
- 护栏采用简化的沿墙擦行模型：接触时最多损失 6% 速度（随碰撞角度变化），持续摩擦额外增加 0.4 m/s² 阻力。不会触发紧急制动、锁定油门或取消驾驶；向内转向可以脱离。
- 周围车辆使用跟车模型及扫掠碰撞检测，避免高速穿车。接触只改变运动，不操作玩家的制动开关。车辆模型不包含真实车体变形。
- 电池按 60 kWh 容量、初始 86% 电量、驱动效率和附件功率累计耗能；设备面板显示电量与即时功率。

模型不包含道路坡度、悬挂、轮胎温度、制动热衰减、真实车辆标定、交通车辆变道或碰撞车体变形。它是交互式物理演示，模拟数值不代表某款真实车辆的制动性能。

## AI 指令演示

支持 `加速到 30 米每秒然后刹车`、`加速到 100 米每秒然后刹车`、`制动测试`、`前进 200 米`、`刹车停止`、`紧急制动`。

制动测试先加速到目标速度，再全力制动并记录距离。前进任务在行驶指定距离后才开始制动，因此总行驶距离还会包含制动过程；计划中会明确显示这一点。任务先展示计划，点击“开始执行”后运行，手动操作会接管任务。急停解除不会自动恢复旧任务。有车流时高目标速度可能无法达到；制动测试 60 秒仍未达速会结束加速、保留自然滑行并提示接管，不报告虚假的制动成绩。

## 文件与检查

- `dist/index.html` / `dist/style.css`：响应式界面。
- `dist/app.js`：驾驶交互、实时显示、任务解析与执行。
- `dist/physics.js`：可单独运行的车辆物理模型。
- `dist/traffic.js`：车流、跟车、车辆接触和路段限速。
- `dist/simulator.js`：高速公路、车辆、限速牌、相机与制动距离可视化。
- `tests/*.test.cjs`：动力学、交通、制动距离及驾驶界面集成检查。
- `dist/health.json`：同源站点往返延迟测量端点。
- `serve.mjs`：本地静态服务。

```sh
node --test tests/*.test.cjs
node --check dist/app.js
node --check dist/simulator.js
```

页面提供可选 WebMCP 接口：读取当前模拟状态、准备任务、触发全力制动。所有接口与界面共用同一车辆状态，均不控制真实硬件。

前一无车流版本验证记录：12 项数值测试通过；浏览器完整运行 100 m/s 制动试验，开始制动速度 99.990 m/s，干地实测 508.592 m，与同模型预测一致。额外检查了油门按住与释放、惯性滑行、常规刹车、急刹锁定与解除、高速降至较低目标后的独立制动计量、干湿路面切换及 390 / 320 像素手机布局。实测 WebGL 画面约 30 FPS，浏览器无运行时异常。

当前车流版本验证：35 项物理、交通及界面集成测试通过，包含碰墙不停油、不触发急停、转向脱离、限速切区与 AI 任务有界结束。浏览器在 390 / 320 px 下无横向溢出，实测约 30 FPS；30 m/s 测试实测制动距离 52.38 m，无控制台警告或错误。当前修改在本地预览验证，线上部署记录仍以 `deploy/ALIYUN.md` 为准。
