# ROVER 高速公路模拟控制台

手机优先的可交互网页，支持在线访问和本地运行，未连接真实车辆。无外部依赖、无需构建。AI 助手采用本地指令解析，不调用外部 AI 服务。

## 本地运行

```sh
git clone https://github.com/loyee001/xinduyuhang.git
cd xinduyuhang
node serve.mjs
```

电脑打开 `http://localhost:4317`。手机与电脑连接同一个 Wi-Fi 后，打开终端打印的 `Same Wi-Fi preview` 地址；电脑需保持服务运行。可用 `PORT=4318 node serve.mjs` 更改端口。

## 驾驶与制动

- 三条普通车道与右侧应急车道，第一人称实时画面、护栏、指示牌和连续延伸的道路。应急车道有独立路面、黄色外缘及 SOS 标识，进入后显示红色警报。优先使用 WebGL，支持 Canvas 2D 备用渲染。目标渲染帧率 30 FPS，界面显示实测帧率。
- 前进目标速度仍可设为 **100 m/s（360 km/h）**，实际驾驶始终遵守所在路段的 **120 / 100 / 80 km/h** 限速（约 33.3 / 27.8 / 22.2 m/s）。油门加速到设定速度与道路限速中的较低值；进入更低限速路段时，超速会触发自动制动，速度按物理模型逐渐降至限速后释放刹车，不会直接跳变或锁定为急停。手动与 AI 驾驶均遵守该规则。
- 按住油门加速；松开油门后因惯性继续行驶，由空气阻力和滚动阻力逐渐减速。降低个人目标速度只限制动力；道路超速保护仍独立工作。
- 周围有独立行驶的轿车和卡车，含同向三车道与对向车流；其他车辆会跟车减速。车流量可切换 **较少 / 中等 / 拥挤**，场景内分别模拟 **42 / 78 / 174 辆车**；拥挤模式有更短车距和更低巡航速度。切换时围绕当前位置重建车流，并在自车前后留出生成间隙，不改变车辆位置或驾驶状态。高速路段的长度与 **120 / 100 / 80 km/h** 限速按世界里程确定性随机生成，相同限速的相邻路段合并。同一位置在往返行驶、切换车流或刷新后保持相同限速，路牌与状态栏同步。
- 底部 **“鸣笛”** 按钮发出短促喇叭声，提醒前方 100 米内最近的同向前车。前车在允许变道且前后车距足够时优先向右避让，右侧不安全时评估左侧；仅进入相邻普通车道，不进入应急或对向车道。实线、前车过慢、快速接近的后车或空间不足时保持车道并显示原因；普通道路和匝道不安排避让。
- 避让按干地约 4 秒、湿地约 5 秒平滑完成，速度降低时随前进行程放慢，停稳不横移。过程中重新检查周围车辆，风险出现时安全返回或暂停并制动；来源与目标车道同时预留空间，其他车辆和自动驾驶会据此跟车。鸣笛有短暂冷却，长按不会连续触发；不会改变自车油门、刹车、自动驾驶或 AI 任务。浏览器无法播放音频时仍显示鸣笛和避让状态。
- 与其他车辆或护栏发生实际碰撞后，**结束并暂停本局**，自车、周围车流及本局计时的物理状态全部冻结。画面先切到车外视角，播放一次整车沿行驶方向腾空前冲、落地滑行和受损冒烟，随后弹窗显示碰撞类型、碰撞前车速和本局行驶距离；保留碰撞模型计算出的速度与位置，不把暂停伪装为瞬间刹停。点击 **“重新开始”** 后回到起点、中间车道、静止 D 挡，重新生成车流；保留控制模式、车流量、干湿路面、目标速度及连接设置。旧的油门输入、制动锁定、出口路线、AI 任务、自动驾驶和鸣笛状态均清除，需要重新操作才会起步。Escape 或点击弹窗外部不会恢复旧一局。
- 碰撞动画随相对撞击速度调整幅度，护栏碰撞按朝向护栏的速度分量计算，轻擦不会按整车高速放大。每次碰撞整车离地 **1.8～3.8 米**，四轮随车身整体抬升；正面与倒车撞击产生相反方向的前后翻转，侧面或偏心碰撞产生侧翻，角速度随撞击强度变化。空中持续旋转，可翻过半圈或一整圈；落地后按剩余角度收敛到车轮、侧面或车顶着地，不会强制回正。底盘、车轴、凹陷和烟源一起随车身转动，地面接触按实际车体网格保留间隙。腾空时沿碰撞前的实际行驶方向继续前冲（倒车则向后），保留部分水平惯性并连续减速；落地后滑行停下，不再上下回弹，也不会移回碰撞点。撞击一端出现凹陷、擦损，车头升起灰烟，停下后保留约 1.2 秒冒烟画面再显示结果。完整过程约 **3.0～4.7 秒**，带随车移动的地面阴影和跟随取景。手机上的碰撞画面会增高，保留整车与烟雾的视野。这是简化碰撞演出：水平位移只影响画面，不继续推进本局里程、速度或车流统计。弹窗可点击 **“回看碰撞动画”** 重播；开启系统减少动态效果时直接显示静态结果。动画中切到后台或相机失效也能重新开始，恢复前台和旋转手机会补绘受损车辆的最终画面。
- **D 前进 / R 倒车**控制行驶方向。行驶中请求换挡会先制动至完全停稳，再换向；不能瞬间反转。R 挡最高 **5 m/s（18 km/h）**，仍按住同一个油门踏板倒车，画面自动朝后，路况栏显示同车道后车距离。倒车也有惯性、制动距离与车辆碰撞。
- 左右按钮每次点按只选择相邻一条车道；松手后自动完成变道、回正并保持车道中央，不会持续转向。变道途中再次点按会提示先等待到达，不连续排队跨越多条车道。停车时只预选目标，按油门起步后才移动。键盘 A / D / 左 / 右执行相同操作，长按不会重复变道；前进和倒车的左右均按道路方向选择。
- **实时推荐变道**卡片显示三条普通车道的前后车距，并根据慢车、相邻车道通行优势、前后车接近速度和路面状态更新建议。仅推荐相邻的一条普通车道，排除应急车道和对向车道；没有明显优势时保持当前车道，间距不足时提示暂缓。点击 **“按推荐向左 / 右变道”** 才会采纳，执行前重新检查车流；原建议失效或方向变化时撤回，不会自动改驶另一方向。采纳后沿用物理变道与自动居中，油门仍由驾驶操作控制。
- 推荐会预测干地 7 秒、湿地 8 秒内的前后间距，并对湿滑路面保留更大的车距；检查并排行驶、快速接近的后车及加速后的前方空间。低速、倒车、制动、换挡、断连、碰撞后、正在变道或应急车道恢复期间暂停推荐；变道完成后至少保持 5 秒再推荐，避免频繁来回变道。建议基于模拟车辆当前位置和速度，交通状态变化时会实时重算。
- 驶离原车道也需要时间：按干地 4 秒、湿地 5 秒检查当前车道前方空间，预计间距不足 10 米时提示先减速拉开车距。建议按钮支持触摸、Enter 和空格；长按不会重复变道。
- 从右侧普通车道继续向右，会驶入应急车道。车辆中心实际越过普通车道右边界（`x > 5.625 m`）后，立即提示并施加全力紧急制动、锁定油门；速度按物理过程下降，仍有制动时间和距离。停稳后点击 **“解除并返回右车道”** 只选择返回目标，不自动加速；需要重新按住油门驶回，回到右车道中央后解除警报。
- 键盘 **A / D 或左右方向键**每次切换一条相邻车道；**W / S 或上下方向键**分别控制油门和刹车，**R** 切换前进 / 倒车，**空格**持续常规制动。AI 页面也能用键盘接管；输入框内打字不会触发驾驶，长按左右键不会连续跨道。
- 道路会在不同里程出现**实线路段**，车道分隔线与路况卡同步改变。实线内禁止变道；开始变道前还会检查按当前速度与目标速度计算的 8 秒路径及车身长度，不能在临近实线时启动无法及时完成的变道。正向和倒车都检查实际行驶方向；手动、推荐与 AI 共用限制。
- 不同里程会出现**可驶入的出口匝道**，配有 EXIT 距离牌、指向箭头、分流区和真实护栏开口。提前到达右车道，接近入口后点击“驶入这个出口”，车辆沿限速 **40 km/h** 的匝道平滑离开高速，再进入限速 **50 km/h** 的普通道路继续行驶。普通道路双向各一条车道，不支持普通变道或再次选择高速出口。在匝道入口前可取消路线。出口路线中的正常跨越路肩不会误触发应急车道急停，普通向右变道进入路肩仍保留保护。
- 出口也有周围车辆驶离：右车道约三分之一车辆按稳定选路规则选择出口，在距离足够时提前减速，沿现有匝道平滑转向并遵守 **40 km/h** 限速；到达普通道路后按 **50 km/h** 继续行驶。未选择出口的车保持主路行驶，选路不会凭空生成车辆或横穿多车道。出口卡片显示准备驶离与沿匝道行驶的实时数量。
- 出口车流会跟随同一路线的前车，并识别自车和干湿路面；车身完全离开主路后释放主路占用。AI 和自动驾驶也会在弯道提前识别同出口前车。自车进入普通道路时保留同出口附近的前后车辆，避免衔接时消失；驶离车辆只在视野外回收。
- 高速沿途约每 **2.4 公里**出现一个**入口汇流区**，位置固定在道路上，带有右侧匝道、加速车道、汇入箭头和距离标志。接近入口时，较少／中等／拥挤车流分别约每 **16／12／8 秒模拟时间**生成一辆入口车；车辆先沿匝道加速，再判断右车道前后间距。车距不足时在渐变段前减速等待，条件恢复后继续汇入；湿滑路面保留更大余量，自车正在向右变道的目标空间也参与判断。
- 汇入车辆在开始并线时预留右车道空间，普通车流、变道建议与自动驾驶会提前考虑它们；并入后成为正常车辆，也能响应鸣笛。入口卡片显示距离和接近、等待、汇入状态。额外入口车辆最多 8 辆，远离后移除；碰撞时共同冻结，重新开始时清空。选择出口路线或进入普通道路后隐藏高速入口提示并停止生成入口车辆。
- 刹车踏板施加 55% 制动力；“常规制动至停止”持续制动。紧急制动施加全力刹车并锁定控制，停稳后才可解除。
- 画面显示制动走廊和预计停车线，数据区显示当前速度、加速度、里程、预计急刹距离和实测制动距离。完整停车结果会保留，未停车就松开刹车的测量取消。
- 干燥 / 湿滑路面改变轮胎附着力。为了保持单次测量条件一致，制动过程中不能切换路面。
- 驾驶中失焦、进入后台、画面失效或断开模拟连接会触发全力制动。重新打开页面时补算停车过程；不会通过直接清零速度实现刹车。若已经发生碰撞，本局继续保持冻结，切回页面不会恢复行驶或继续补算。

## 自动驾驶

打开 **“自动驾驶”** 标签，选择 **“沿道路巡航”** 或 **“下个出口驶离”**，再点击 **“启动自动驾驶”**。启动后自动控制油门、刹车和车道居中，无需持续按住油门；状态卡实时显示当前判断及控制输入。

- 巡航按个人目标与道路限速控制速度，提前观察前方更低限速并按物理过程减速；前方有慢车或停车队列时减速跟车，湿滑路面保留更大间距。
- 车道通行条件有明显改善时，复用前后车距检查、实线限制与变道冷却，再执行相邻普通车道变道；应急车道和对向车道不参与选择。无法安全变道时保持车道并跟车。
- 选择出口行程后提前靠右，按 **40 km/h** 匝道限速驶离高速，接入普通道路后继续按 **50 km/h** 限速在本车道巡航。无法安全驶入当前出口时继续选择后续可用出口，不强行跨越车道。
- 点击 **“结束自动驾驶并停车”** 会退出自动驾驶并持续制动至停稳。手动驾驶操作、切换控制方式或新的 AI 任务会接管；急停、失焦、后台与断连仍触发原有制动保护，恢复页面不会自动重新启动。
- 若实际发生碰撞，自动驾驶和正在执行的行程立即取消，与手动驾驶共用碰撞暂停和重新开始机制；重开后保持待命，需要再次点击启动。

这是浏览器内的简化交通模拟，不连接真实车辆。自动驾驶与手动、AI 任务共用车辆动力学和道路规则，不通过直接修改坐标或速度完成行程。

## 物理模型

平直道路上的简化车辆动力学，每步不超过 1/120 秒：

- 质量 1,400 kg，轴距 2.7 m，底层模型的前进上限为 100 m/s，倒车上限为 5 m/s；网页驾驶时另受实际路段限速约束。
- 驱动力受 8,000 N 最大牵引力、650 kW 峰值功率及路面附着力限制。
- 空气阻力 `F = 0.5 × ρ × CdA × v²`，空气密度 1.225 kg/m³，CdA 0.66 m²。
- 滚动阻力 `F = Crr × m × g`，Crr = 0.012，g = 9.81 m/s²。
- 干燥摩擦系数 μ = 0.85，湿滑 μ = 0.45。转向采用自行车模型，转向角变化有速率限制，横向与纵向轮胎力受附着圆约束。
- 制动距离通过与车辆运动相同的阻力和制动模型计算。预计急刹距离是**当前速度下全力直线制动的距离，不包含反应距离**；实测值从踩下刹车起累计真实模拟路径，前进、倒车均计为正距离。常规制动、自动限速制动、转弯或碰撞会让实测值与全力直线预测不同。
- 三条普通车道中心位于 `x = -3.75 / 0 / 3.75 m`；右应急车道范围为 `5.625～8.625 m`、中心为 `7.125 m`。车辆中心的护栏限制为左侧 `-6.45 m`、右侧 `7.95 m`，应急车道能够容纳整车。
- 变道控制器通过转向输入跟踪目标车道，接近中央时回正；它不直接修改车辆位置或朝向，仍使用自行车模型与轮胎附着力限制。
- 底层护栏物理模型保持简化的沿墙擦行算法：接触时最多损失 6% 速度（随碰撞角度变化），持续摩擦额外增加 0.4 m/s² 阻力，向内转向可离开护栏。网页在首次实际接触的物理步完成后立即暂停本局，因此不会继续执行后续擦行。右侧应急车道仍在实际进入时触发全力制动，通常早于护栏碰撞；仅进入应急车道不算碰撞。
- 周围车辆使用跟车模型、鸣笛触发的渐进避让及扫掠碰撞检测，避让中的侧向位移与车身朝向也参与碰撞判断，避免高速穿车；倒车时根据实际运动方向处理后车接触。底层碰撞算法仍负责修正位置、速度及距离，不直接操作制动开关；网页检测到碰撞后取消驾驶任务并冻结整局，直到用户重新开始。车辆模型不包含真实车体变形。
- 电池按 60 kWh 容量、初始 86% 电量、驱动效率和附件功率累计耗能；设备面板显示电量与即时功率。

模型不包含道路坡度、悬挂、轮胎温度、制动热衰减、真实车辆标定或碰撞车体变形。周围车辆的鸣笛避让与入口汇入采用与行驶速度关联的简化轨迹和间距预测，不模拟真实驾驶员的反应差异、主动超车或完整轮胎动力学。它是交互式物理演示，模拟数值不代表某款真实车辆的制动性能。

## AI 指令演示

AI 助手使用本地指令识别，支持组合**距离、变道、调速、制动、停车等待、倒车和出口**，无需外部 AI 服务。输入最多 240 字，一个计划最多 8 步（含拆分的多车道变更与自动停车）。示例：

- `直行500米后向左变道并制动`
- `以60公里每小时行驶300米然后停车`
- `前进200米，然后向右变道，再等待5秒`
- `倒车10米，然后停车`
- `从下一个出口驶离高速`
- `从下一个出口驶离高速，然后直行300米并停车`
- `加速到30米每秒然后刹车`、`制动测试`、`刹车停止`、`紧急制动`

可用“然后、后、再、并”等连接动作，数字支持常用中文与阿拉伯数字，距离支持米 / 公里，速度支持 m/s / km/h。无法识别的剩余内容会明确报错，不会只执行前半句。计划先逐步展示，确认“开始执行”后才运行。以行驶距离、变道或调速结尾的计划会自动追加停车；以“驶离高速”结尾的计划不隐含停车，进入普通道路后转为 AI 限速巡航，直到手动接管或下达“停车 / 制动”等停止指令。手动接管会取消后续动作。

例如“直行500米后向左变道并制动”会先完成直行距离，再等待允许变道的路段、完成左变道并回正，最后制动；实线内不会直接横跨车道，等待原因会显示在计划中。驶离出口任务会先接近出口并选择右车道，再沿真实匝道进入普通道路。“从下一个出口驶离高速，然后直行300米并停车”会在普通道路上继续完成 300 米行程，再按物理过程制动；出口之后还可接调速、倒车、等待与制动步骤。道路限速、实线限制与车道边界在执行复合计划时仍然生效。

制动测试先加速到道路允许的目标速度，再全力制动并记录距离。例如在 120 km/h 路段输入“加速到 100 米每秒然后刹车”，计划会调整为约 33.3 m/s，再执行制动，不会尝试突破路段限速。跨入其他限速路段时，实际目标随道路限速调整。

前进与倒车任务在行驶指定距离后才开始制动，因此总行驶距离还会包含制动过程；计划中会明确显示这一点。反向任务先停稳换挡。任务先展示计划，点击“开始执行”后运行，手动操作会接管任务。急停解除不会自动恢复旧任务。有车流时，即使已按限速调整，目标速度仍可能无法达到；制动测试 60 秒仍未达速会结束加速、保留自然滑行并提示接管，不报告虚假的制动成绩。
